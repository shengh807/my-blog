이 블로그에 새 글을 올리는 방법은 아주 간단합니다.

## 1. 새 글 파일 만들기

터미널에서 아래 명령어를 실행하면 오늘 날짜로 초안 파일이 자동으로 만들어집니다.

```bash
npm run new "글 제목"
```

`posts/` 폴더에 `2026-08-21-글-제목.md` 같은 파일이 생성됩니다.

## 2. 내용 작성하기

파일을 열어보면 이렇게 생겼습니다.

```markdown
---
title: "글 제목"
date: "2026-08-21"
tags: []
description: ""
draft: true
---

여기에 내용을 작성하세요.
```

`---` 사이에 있는 부분을 **프런트매터**라고 부르며, 글의 제목·날짜·태그 같은 정보를 담습니다. 그 아래에 본문을 마크다운으로 자유롭게 작성하면 됩니다.

## 3. 발행하기

글을 다 쓰셨다면 `draft: true`를 `draft: false`로 바꿔주세요. `draft: true`인 글은 빌드에 포함되지 않습니다.

그다음 아래 명령어로 사이트를 다시 빌드합니다.

```bash
npm run build
```

`docs/` 폴더에 결과물이 생성되고, 배포된 사이트에도 그대로 반영됩니다 (배포 방법은 README를 참고하세요).

## 팁

- 로컬에서 미리 보고 싶다면 `npm run preview`를 실행하세요.
- 이미지는 `assets/` 폴더에 넣고 `![설명](/assets/파일명.jpg)` 형식으로 불러올 수 있습니다.
- 태그는 여러 개를 지정할 수 있습니다: `tags: ["일상", "여행"]`
